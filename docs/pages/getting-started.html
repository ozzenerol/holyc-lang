Getting started

Build hcc from source, then compile and run your first programs.

Requirements

  • Linux on x86_64 or arm64, or macOS on Apple Silicon (arm64); macOS on Intel is not supported. On Windows, use WSL2.
  • A C compiler (gcc or clang), make and cmake. hcc uses the C compiler to assemble and link the code it generates.
  • Optional: the SQLite development package, for the SQLite bindings.

Build

From the repository root, run as your normal user (not with sudo):

./build.sh

This builds the compiler as ./hcc and the standard library into build/prefix. Useful options:

CommandWhat it does
./build.sh --testBuild, then run the unit, JIT and LSP test suites
./build.sh --installAlso install hcc and the library to /usr/local (asks for sudo only for the copy)
./build.sh --sqliteInclude the SQLite bindings
./build.sh --debugDebug build with AddressSanitizer
./build.sh --cleanStart from scratch

Set INSTALL_PREFIX=$HOME/.local to install somewhere else, and CC=clang to choose the C compiler. The classic route also works: make && sudo make install.

Without installing. A program needs the standard library to compile. If you haven't installed hcc, point it at the local build with --install-dir:

./hcc --install-dir=build/prefix hello.HC -o hello

The rest of these docs assume hcc is installed and on your PATH.

Your first program

Create hello.HC:


U0 Main()
{
  "Hello, %s!\n", "world";
}

Hello, world!

A string literal on its own line is a print statement: it works like printf, with any arguments after a comma. Compile and run it:

hcc hello.HC -o hello
./hello

Without -o the binary is called a.out.

Run without compiling a binary

The JIT compiles into memory and runs immediately, which is handy while developing:

hcc -jit hello.HC

Make a file executable as a script with a shebang line. hcc skips a first line that starts with #!:

#!/usr/bin/env -S hcc -jit
"Hello from a script\n";
chmod +x hello.HC
./hello.HC

How a program runs

Statements at the top level of a file run in order, as in a script. If you define Main, it runs after them:


"first\n";

U0 Main()
{
  "last\n";
}

"second\n";

first
second
last

Small programs can skip Main entirely and just write statements. Larger ones usually keep their code in functions.

Return a value from Main to set the exit code:

I32 Main()
{
  return 3;   // ./a.out; echo $? prints 3
}

The standard library

Every program can use the whole standard library (MAlloc, StrPrint, hash tables, JSON and the rest) without an #include. The compiler reads its header, tos.HH, automatically and links libtos. See the library guide.

Several files

Pull other files in with #include. Paths in quotes are relative to the including file:

// main.HC
#include "geometry.HC"

U0 Main()
{
  "%d\n", Area(3, 4);
}
// geometry.HC
I64 Area(I64 w, I64 h)
{
  return w * h;
}
hcc main.HC -o shapes
