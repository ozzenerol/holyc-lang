Library guide

How to use the standard library for everyday tasks. Every program can use it without an #include. For every function and class, see the library reference.

Memory

FunctionDoes
MAlloc(size)Allocate size bytes
CAlloc(size)Allocate zeroed bytes
ReAlloc(ptr, size)Resize an allocation
Free(ptr)Release it (NULL is fine)
MSize(ptr)Usable size of an allocation
MemCpy(dst, src, n), MemSet(dst, byte, n)Copy and fill
 

class Player
{
  U8 *name;
  I64 score;
};

U0 Main()
{
  Player *team = CAlloc(3 * sizeof(Player));
  team[0].name = "ada";
  team[0].score = 10;
  team = ReAlloc(team, 4 * sizeof(Player));
  team[3].name = "linus";
  "%s %d, %s\n", team[0].name, team[0].score, team[3].name;
  Free(team);
}

ada 10, linus

Run a program with hcc -jit -Memsafe file.HC to have double frees and wild frees reported (and skipped) as they happen, and leaks reported at exit, each with the line that allocated or freed the block. Only blocks your code gets from MAlloc, CAlloc and ReAlloc are tracked: a string or container the standard library allocates for you (StrNew, StrPrint, PtrVecNew, ...) is not, so leaking one goes unreported, and a block of yours that the library resizes (CatLenPrint) is reported as never freed.

Strings

Building strings

StrPrint(NULL, fmt, ...) returns a newly allocated formatted string, and CatPrint(s, fmt, ...) returns a new string made of s followed by the formatted text. Unlike print statements, their %d is a full 64-bit integer. %f, %e and %g print a float the way C's printf does, with the same rounding.


U0 Main()
{
  U8 *s = StrPrint(NULL, "%d|%05d|%s|%.2f", 5000000000, 42, "x", 3.14159);
  "%s\n", s;

  U8 *csv = StrNew("id");
  for (I64 i = 1; i <= 3; i++) {
    csv = CatPrint(csv, ",%d", i);
  }
  "%s\n", csv;

  U8 *joined = StrMerge("con", "cat", "enate");
  "%s\n", joined;
  Free(s);
  Free(csv);
  Free(joined);
}

Inspecting strings


U0 Main()
{
  "%d %d\n", StrLen("hello"), StrCmp("abc", "abc") == 0;
  "%d\n", StrNCmp("prefix-rest", "prefix", 6) == 0;
  "%d %d\n", StrCmp("abc", "abd") < 0, StrNICmp("ABC", "abc", 3) == 0;
  "%d\n", StrOcc("banana", 'a');               // count a character
  "%s\n", StrFirstOcc("key=value", "=");       // from the first match
  "%s\n", StrLastOcc("a/b/c.HC", "/");         // from the last match
  "%s\n", FileExtDot("archive.tar.gz");
  "%d %d\n", WildMatch("main.HC", "*.HC"), WildMatch("main.c", "*.HC");
  "%d\n", Atoi("1234") + 1;
  "%c %c %d\n", ToUpper('q'), ToLower('Q'), IsSpace(' ');
}

Files

FileWrite writes a buffer to a file and returns whether it worked. FileRead reads a whole file into a new NUL-terminated buffer, or returns NULL if it can't.


U0 Main()
{
  U8 *path = "/tmp/hcc_docs_example.txt";
  U8 *text = "first line\nsecond line\n";
  if (!FileWrite(path, text, StrLen(text))) {
    "could not write %s\n", path;
    return;
  }

  I64 size;
  U8 *contents = FileRead(path, &size);
  "%d bytes\n%s", size, contents;
  Free(contents);

  if (FileRead("/no/such/file", &size) == NULL) {
    "missing files give NULL\n";
  }
}

second line

For lower-level work the POSIX calls (open, read, write, close, lseek) are declared too, along with Stat, Rm, RmDir, Cd, Pwd and Dir.

Running commands


U0 Main()
{
  I64 status = System("echo from the shell");
  Sh("echo %s has %d files", "/tmp", 3);    // printf-style
  U8 *out = Shlurp("echo %s", "captured");  // capture stdout

  "exit status %d\n", status;
  "[%s]\n", out;
  Free(out);
}

from the shell
/tmp has 3 files
exit status 0
[captured]

Print statements are buffered, while commands write straight to the terminal. When output goes to a pipe or file, a command's output can appear before text you printed earlier.

Shlurp returns what the command printed to stdout, minus one trailing newline, as a string to Free; format arguments are optional. It doesn't capture stderr or return the exit status: a failing command gives whatever it printed, often "". Exit(code) ends the program.

Lists

List is a circular doubly linked list of U0 * values. The list head is a sentinel, so iterate from l->next until you get back to l.


U0 Main()
{
  List *l = ListNew();
  ListAppend(l, "two");
  ListAppend(l, "three");
  ListPrepend(l, "one");

  for (List *it = l->next; it != l; it = it->next) {
    "%s\n", it->value;
  }
  "popped %s, %d left\n", ListPop(l), ListCount(l);
}

two
three

Vectors

Growable arrays: IntVec of I64, FloatVec of F64 and PtrVec of pointers. Each has size and entries fields, so a range-based for works on them.

PtrVecSort takes a comparison that returns TRUE when its first argument should come first. That's a "less than" test, not a C-style negative, zero or positive result.


I64 ShorterFirst(U0 *a, U0 *b)
{
  return StrLen(a) < StrLen(b);
}

U0 Main()
{
  IntVec *nums = IntVecNew();
  IntVecPush(nums, 30);
  IntVecPush(nums, 10);
  IntVecPush(nums, 20);
  IntVecSort(nums);
  for (I64 n : nums) {
    "%d\n", n;
  }
  Bool ok;
  "popped %d, size %d, first %d\n", IntVecPop(nums, &ok), nums->size, IntVecGet(nums, 0);
  IntVecRelease(nums);

  PtrVec *words = PtrVecNew();
  PtrVecPush(words, "banana");
  PtrVecPush(words, "fig");
  PtrVecPush(words, "apple");
  PtrVecSort(words, &ShorterFirst);
  for (U8 *w : words) {
    "%s\n", w;
  }
  PtrVecRelease(words);
}

Hash tables

StrMap maps strings to U0 * values and IntMap maps I64 keys. Values are pointers, so cast integers when storing them: count(U0 *). Setting an existing key replaces its value.


U0 Main()
{
  StrMap *stock = StrMapNew();
  StrMapSet(stock, "apples", 3(U0 *));
  StrMapSet(stock, "pears", 5(U0 *));
  StrMapSet(stock, "apples", 4(U0 *));
  StrMapSet(stock, "plums", 7(U0 *));
  StrMapDelete(stock, "plums");

  "%d apples, has kiwis: %d, %d keys\n",
    StrMapGet(stock, "apples"), StrMapHas(stock, "kiwis"), stock->size;

  I64 idx = 0;
  StrMapNode *node;
  while (StrMapIter(stock, &idx, &node)) {
    "%s = %d\n", node->key, node->value;
  }
  StrMapRelease(stock);

  IntMap *names = IntMapNew();
  IntMapSet(names, 404, "not found");
  IntMapSet(names, 200, "ok");
  "%s\n", IntMapGet(names, 404);
  "deleted 200: %d, deleted 500: %d\n", IntMapDelete(names, 200), IntMapDelete(names, 500);
  IntMapRelease(names);
}

4 apples, has kiwis: 0, 2 keys
apples = 4
pears = 5
not found
deleted 200: 1, deleted 500: 0

Iteration follows insertion order. StrMapSetFreeValue and StrMapSetFreeKey register destructors that run on replace and release. StrMapNew and IntMapNew take an optional starting capacity (default 32), rounded up to a power of two; the table grows as you add keys. Setting an existing key keeps the key already stored. With destructors registered the map owns what you give it: an update frees the value it replaces and the duplicate key you passed (never the stored key, and nothing when you pass the stored pointers again). StrMapDelete and IntMapDelete remove a key, running the destructors on it, and return FALSE if the key wasn't there; iteration skips deleted keys and keeps the order of the rest, and a deleted key can be set again (it then comes last).

The map keeps the key pointer you pass the first time a key is set, instead of copying it. Use keys that live as long as the map, such as StrNew copies; updating an existing key from a reused buffer is fine.

JSON

JsonParse parses text into a tree of Json nodes. Check JsonOk before using the result. JsonSelect walks a path: .field for object members and [n] for array elements, with a type suffix that must match (:s string, :i integer, :f float, :b boolean, :a array, :o object). It returns NULL if the path or type doesn't match.


U0 Main()
{
  U8 *text = "{\"name\": \"hcc\", \"version\": 15, \"ratio\": 0.75, \"tags\": [\"jit\", \"repl\"], \"stable\": false}";
  Json *doc = JsonParse(text);
  if (!JsonOk(doc)) {
    JsonPrintError(doc);
    return;
  }

  "%s v%d\n", JsonSelect(doc, ".name:s")->str, JsonSelect(doc, ".version:i")->i64;
  "second tag: %s\n", JsonSelect(doc, ".tags[1]:s")->str;
  "stable: %d\n", JsonSelect(doc, ".stable:b")->boolean;
  "missing: %d\n", JsonSelect(doc, ".author:s") == NULL;

  Json *tags = JsonSelect(doc, ".tags:a");
  for (Json *t = tags->array; t; t = t->next) {
    "tag %s\n", t->str;
  }

  "%s\n", JsonToString(doc);
  JsonRelease(doc);
}

hcc v15
second tag: repl
stable: 0
missing: 1
tag jit
tag repl
{"name": "hcc","version": 15,"ratio": 0.75,"tags": ["jit","repl"],"stable": false}

Each node has a type (JSON_STRING, JSON_INT, JSON_FLOAT, JSON_BOOL, JSON_NULL, JSON_ARRAY, JSON_OBJECT), a key when it's an object member, its value in str / i64 / f64 / boolean / array / object, and next for its siblings. JsonToString writes a float in the shortest form that reads back as the same value, always with a decimal point (0.75, 2.0, 1.0e+21).

Dates and time


U0 Main()
{
  U64 start = NowMilliseconds();

  CDateStruct ds;
  NowDateTimeStruct(&ds);
  "year looks right: %d\n", ds.year >= 2024;

  U8 *stamp = MPrintTimestampNow();     // like 2026-10-08 19:01:37
  "timestamp is %d characters\n", StrLen(stamp);

  "elapsed ms is never negative: %d\n", NowMilliseconds() >= start;

  MemSet(&ds, 0, sizeof(CDateStruct));  // Struct2Date reads every field
  ds.year = 2024;
  ds.mon = 2;
  ds.day_of_mon = 29;
  ds.hour = 12;
  ds.min = 34;
  CDate leap = Struct2Date(&ds);
  "%s %s\n", MPrintDate(leap), MPrintTime(leap);

  CDateStruct back;
  Date2Struct(&back, leap);
  "%d-%02d-%02d, day of week %d\n", back.year, back.mon, back.day_of_mon,
    back.day_of_week;
}

Now() returns a TempleOS-style CDate, and Date2Struct / Struct2Date convert between it and a CDateStruct, which has year, mon, day_of_mon, hour, min, sec and day_of_week (0 is Sunday). MPrintDate and MPrintTime return new strings as MM/DD/YYYY and HH:MM:SS.

Maths

The C maths library is declared under its usual names (sqrt, pow, sin, floor, fabs, …, all on F64), plus Abs, Gcd and Pow. Gcd ignores signs: Gcd(0, n) is |n| and Gcd(0, 0) is 0.


U0 Main()
{
  "%.4f %.0f %.1f %.1f\n", sqrt(2.0), pow(2.0, 10.0), floor(2.7), fabs(-1.5);
  "%d %d %d %.2f\n", Abs(-5), Gcd(12, 18), Gcd(-4, 0), Pow(1.5, 2);
}

1.4142 1024 2.0 1.5
5 6 4 2.25

More modules

These are covered in the library reference:

  • Threads: pthreads (pthread_create, mutexes, condition variables) plus ThreadWorker helpers.
  • Networking: sockets, getaddrinfo and friends.
  • CSV: CsvParserInit and CsvParse, a streaming tokenizer.
  • Fuzzy matching: fzf-style scoring.
  • Sets: red-black-tree-backed integer and string sets.
  • SQLite: when hcc is built with --sqlite.
