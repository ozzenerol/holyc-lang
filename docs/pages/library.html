Library guide

How to use the standard library for everyday tasks. Every program can use it without an #include. For every function and class, see the library reference.

Memory

class Player
{
  U8 *name;
  I64 score;
};

U0 Main()
{
  Player *team = CAlloc(3 * sizeof(Player));
  team[0].name = "ada";
  team[0].score = 10;
  team = ReAlloc(team, 4 * sizeof(Player));
  team[3].name = "linus";
  "%s %d, %s\n", team[0].name, team[0].score, team[3].name;
  Free(team);
}

ada 10, linus

Run a program with hcc -jit -Memsafe file.HC to have double frees and wild frees reported (and skipped) as they happen, and leaks reported at exit, each with the line that allocated or freed the block. Only blocks your code gets from MAlloc, CAlloc and ReAlloc are tracked: a string or container the standard library allocates for you (StrNew, StrPrint, PtrVecNew, ...) is not, so leaking one goes unreported, and a block of yours that the library resizes (CatPrint, CatLenPrint) is reported as never freed.

Strings

A string is a NUL-terminated U8 array. Functions that make a string (StrNew, StrPrint(NULL, ...), MStrPrint, StrMerge, StrNCpy, MPrintQ, MPrintDate, MPrintTime, MPrintTimestampNow) return a new block that you Free. The trimming and ...Rem functions change the string you pass, in place, so give them a copy rather than a literal. Case conversion and the case-insensitive compares only know ASCII letters.

Building strings

StrPrint(NULL, fmt, ...) returns a newly allocated formatted string, and CatPrint(s, fmt, ...) appends the formatted text to the heap string s and returns it, so write s = CatPrint(s, fmt, ...): when s is full it is grown, which may move it and frees the old block. s must come from MAlloc, StrNew, StrPrint(NULL, ...) or an earlier CatPrint, or be NULL to start a new string; never pass a string literal or a stack buffer. CatPrint measures s on every call, so appending in a long loop is quadratic; CatLenPrint(s, &len, fmt, ...) keeps the length in len and doesn't. StrMerge("a", "b", ...) joins strings and MStrPrint(fmt, ...) is StrPrint into an exactly sized block.


U0 Main()
{
  U8 *s = StrPrint(NULL, "%d|%05d|%s|%.2f", 5000000000, 42, "x", 3.14159);
  "%s\n", s;

  U8 *csv = StrNew("id");
  for (I64 i = 1; i <= 3; i++) {
    csv = CatPrint(csv, ",%d", i);
  }
  "%s\n", csv;

  I64 len = 0;
  U8 *log = NULL;
  for (I64 i = 0; i < 3; i++) {
    log = CatLenPrint(log, &len, "[%d]", i * i);
  }
  "%s (%d)\n", log, len;

  U8 *joined = StrMerge("con", "cat", "enate");
  "%s\n", joined;
  Free(s);
  Free(csv);
  Free(log);
  Free(joined);
}

Format conversions

StrPrint, CatPrint and the other formatting functions share one format language with print statements. Integers are always 64-bit, and the C length modifiers l, ll, h, hh, z and j are accepted and ignored, so C formats can be pasted in.

ConversionPrints
%d %ia signed integer
%uan unsigned integer
%x %X %ohexadecimal (lower / upper case), octal
%f %e %gan F64, as C's printf prints it
%sa string
%c %Ca character; a multi-character constant like 'abc' prints all its characters (up to 8), %C in upper case; the value 0 prints nothing
%pa pointer as 0x and 16 hex digits
%D %Ta CDate as MM/DD/YYYY / HH:MM:SS
%Qa string escaped for a C literal (MPrintQ)
%Fthe contents of the file whose name is the argument (nothing if it can't be read)
%%a % (a width on it is ignored)

Between the % and the letter come, in order: the flags - (left justify), 0 (pad with zeros), + (always a sign), a space (a space where a plus sign would go) and # (0x / 0 prefix for hex and octal); a width; and a precision after a ., which is the number of decimals for floats, the maximum length for %s and the minimum number of digits for integers (%.3d of 7 is 007). Width and precision can be *, taken from the arguments. An unknown conversion is printed as it was written, with a warning on stderr, and still uses up its argument, so the ones after it stay in place.

StrPrint(buf, fmt, ...) writes into buf with no bound. For a fixed-size buffer use StrNPrint(buf, size, fmt, ...), which works like C's snprintf: it writes at most size - 1 characters and always ends them with a '\0', cutting longer output short. It returns buf.


U0 Main()
{
  U8 *s = StrPrint(NULL, "%+d|% d|%#x|%#o|%.3d|%ld|%-4s|%5.1f", 7, 7, 255, 8, 7,
                   5000000000, "ab", 2.25);
  "%s\n", s;
  Free(s);

  U8 small[8];
  StrNPrint(small, sizeof(small), "%s-%d", "overflow", 12345);
  "[%s] %d\n", small, StrLen(small);
}

Inspecting strings

StrCmp, StrNCmp and StrNICmp return a negative, zero or positive number like C's strcmp, comparing bytes as unsigned, and sort a NULL before every string. StrFirstOcc and StrLastOcc find the first or last character of the first string that is any of the characters in the second. WildMatch matches a whole string against a pattern where * is any run of characters and ? any one character. StrHash gives a well mixed 64-bit hash of a string.


U0 Main()
{
  "%d %d\n", StrLen("hello"), StrCmp("abc", "abc") == 0;
  "%d\n", StrNCmp("prefix-rest", "prefix", 6) == 0;
  "%d %d\n", StrCmp("abc", "abd") < 0, StrNICmp("ABC", "abc", 3) == 0;
  "%d\n", StrOcc("banana", 'a');               // count a character
  "%s\n", StrFirstOcc("key=value", "=");       // from the first match
  "%s\n", StrLastOcc("a/b/c.HC", "/");         // from the last match
  "%s\n", FileExtDot("archive.tar.gz");
  "%d %d %d\n", WildMatch("main.HC", "*.HC"), WildMatch("main.c", "*.HC"),
    WildMatch("banana", "b?n*a");
  "%d\n", Atoi("1234") + 1;
  "%c %c %d\n", ToUpper('q'), ToLower('Q'), IsSpace(' ');
}

Copying and trimming

StrNew copies a whole string and StrNCpy(s, n) at most the first n bytes of it, like C's strndup (a negative n is 0). StrCpy copies into a buffer you provide. StrTrimStart and StrTrimEnd remove whitespace in place and return the same pointer; pass a length as the second argument to look only at that many bytes, or -1 for the whole string.


U0 Main()
{
  U8 *copy = StrNew("  padded  ");
  I64 len;
  StrTrimStart(copy, -1, &len);
  "[%s] %d\n", copy, len;
  StrTrimEnd(copy, -1, &len);
  "[%s] %d\n", copy, len;

  U8 *part = StrNCpy("truncate me", 8);
  "[%s]\n", part;

  U8 buf[16];
  StrCpy(buf, "fixed");
  "%s\n", buf;
  Free(copy);
  Free(part);
}

Splitting paths and names

These follow TempleOS. StrFirstRem(s, markers, dst) moves the part before the first marker character into dst and leaves the rest in s; StrLastRem does the same with the part after the last marker. Both change s in place, and dst may be NULL. FileExtRem(name, dst) cuts the extension off name and puts it, without the dot, in dst. FileExtDot finds the first . that isn't followed by / or ., and IsDotZ / IsDotC are TRUE for TempleOS names like Doc.HC.Z: the name must end in .Z / .C and have another dot before it.


U0 Main()
{
  U8 path[32], first[16], last[16], ext[8];
  StrCpy(path, "usr/lib/libtos.a");
  StrFirstRem(path, "/", first);
  "%s + %s\n", first, path;
  StrLastRem(path, "/", last);
  "%s + %s\n", path, last;
  FileExtRem(last, ext);
  "%s . %s\n", last, ext;
  "%d %d\n", IsDotZ("Doc.HC.Z"), IsDotZ("Doc.Z");
}

I64ToStr and U64ToStr are internal helpers of the formatter: they write the digits least significant first and without a sign. Use StrPrint to turn a number into text.

Files

FileWrite writes a buffer to a file and returns whether it worked. FileRead reads a whole file into a new NUL-terminated buffer, or returns NULL if it can't.


U0 Main()
{
  U8 *path = "/tmp/hcc_docs_example.txt";
  U8 *text = "first line\nsecond line\n";
  if (!FileWrite(path, text, StrLen(text))) {
    "could not write %s\n", path;
    return;
  }

  I64 size;
  U8 *contents = FileRead(path, &size);
  "%d bytes\n%s", size, contents;
  Free(contents);

  if (FileRead("/no/such/file", &size) == NULL) {
    "missing files give NULL\n";
  }
}

Running commands


U0 Main()
{
  I64 status = System("echo from the shell");
  Sh("echo %s has %d files", "/tmp", 3);    // printf-style
  U8 *out = Shlurp("echo %s", "captured");  // capture stdout

  "exit code %d\n", status;
  "[%s]\n", out;
  Free(out);
}

from the shell
/tmp has 3 files
exit code 0
[captured]

Print statements are buffered, while commands write straight to the terminal. When output goes to a pipe or file, a command's output can appear before text you printed earlier.

System and Sh run the command with sh -c and return its exit code, 0 to 255: System("exit 3") gives 3, and a command the shell can't find gives 127. They return -1 if the command was killed by a signal or the shell couldn't be run.

Shlurp returns what the command printed to stdout, minus one trailing newline, as a string to Free; format arguments are optional. It doesn't capture stderr or return the exit status: a failing command gives whatever it printed, often "". Exit(code) ends the program.

Lists

List is a circular doubly linked list of U0 * values. The list is its head node, which links to itself when the list is empty, so iterate from l->next until you get back to l. The list never frees the values it holds unless you hand it a free function.


U0 Main()
{
  List *l = ListNew();
  ListAppend(l, "two");
  ListAppend(l, "three");
  ListPrepend(l, "one");

  for (List *it = l->next; it != l; it = it->next) {
    "%s\n", it->value;
  }
  "first %s, last %s\n", ListFirst(l), ListLast(l);
  "popped %s, %d left\n", ListPop(l), ListCount(l);
  ListRelease(l, NULL);
}

  • Making one. ListNew() allocates a head; free it with ListRelease. ListInit(&head) turns a head you own (on the stack, or inside a class) into an empty list; empty that one with ListClear, because ListRelease also frees the head.
  • Adding. ListAppend and ListPrepend add at the end and the front; ListInsertValueBefore(node, value) inserts before any node (before the head is the end), and ListInsertBefore(node, new_node) links in a node you made yourself.
  • Removing. ListDeque removes and returns the first value and ListPop the last, so ListAppend with ListDeque is a first-in first-out queue and ListAppend with ListPop a stack. ListRemove(node) unlinks one node while you walk the list (take it->next first) and returns its value; never pass it the head.
  • Looking. ListFirst and ListLast return a value without removing it, ListEmpty tells whether there are any, and ListCount counts them by walking the list, so it is O(n).
  • Emptying. ListClear(l, free_value) frees every node and keeps the head; ListRelease(l, free_value) frees the nodes and the head. Both call free_value on each value when it isn't NULL.
  • Joining. ListMergeAppend(l1, l2) and ListMergePrepend(l1, l2) move all of l2's values to the end or the front of l1 and free l2's head, so l2 (which must come from ListNew) can't be used afterwards.

ListDeque, ListPop, ListFirst and ListLast return NULL for an empty list, which looks the same as a stored NULL: check ListEmpty first if you store them. The functions that remove, look or free accept a NULL list and do nothing (returning NULL, 0 from ListCount, TRUE from ListEmpty); the ones that add need a real list.


U0 Main()
{
  List todo;              // a head on the stack
  ListInit(&todo);
  ListAppend(&todo, StrNew("write"));
  ListAppend(&todo, StrNew("test"));
  ListAppend(&todo, StrNew("ship"));

  List *it = todo.next;
  while (it != &todo) {   // drop "test" while walking
    List *next = it->next;
    if (!StrCmp(it->value, "test")) Free(ListRemove(it));
    it = next;
  }

  List *later = ListNew();
  ListAppend(later, StrNew("rest"));
  ListMergeAppend(&todo, later);   // `later` is freed

  for (it = todo.next; it != &todo; it = it->next) "%s ", it->value;
  "(%d)\n", ListCount(&todo);
  ListClear(&todo, &Free);         // keeps the stack head
  "empty: %d\n", ListEmpty(&todo);
}

Vectors

Growable arrays: IntVec of I64, FloatVec of F64 and PtrVec of pointers. Each has size and entries fields, so a range-based for works on them. The functions are the same for the three, with the type as prefix:

  • IntVecNew(size = 32) makes an empty vector with room for size values (its initial capacity); a size below 1 is taken as 1. IntVecCapacity says how many values fit before the storage has to grow, and IntVecPush appends, doubling the storage when it is full.
  • IntVecGet(v, i) and IntVecSet(v, i, value) read and replace an entry. The index is always checked: outside 0 to size - 1 they print IntVecGet: index 5 out of range (size 3) on stderr and exit with status 1. Reading v->entries[i] directly is not checked.
  • IntVecPop(v, &ok) removes and returns the last entry and IntVecLast(v, &ok) returns it without removing it. On an empty vector they return -1 (-1.0 for FloatVec, NULL for PtrVec) and set ok to FALSE; the ok argument is optional.
  • IntVecClear sets the size to 0 and keeps the storage for reuse; IntVecRelease frees it. PtrVecRelease(v, free_value) first calls free_value (for example &Free) on every value.
  • IntVecSort and FloatVecSort sort ascending. PtrVecSort takes a comparison that returns TRUE when its first argument should come first. That's a "less than" test, not a C-style negative, zero or positive result, which leaves the vector unsorted. The sorts are O(n log n), also for sorted or all-equal input, and not stable: equal values may change order.

I64 ShorterFirst(U0 *a, U0 *b)
{
  return StrLen(a) < StrLen(b);
}

U0 Main()
{
  IntVec *nums = IntVecNew();
  IntVecPush(nums, 30);
  IntVecPush(nums, 10);
  IntVecPush(nums, 20);
  IntVecSort(nums);
  for (I64 n : nums) {
    "%d\n", n;
  }
  IntVecSet(nums, 0, 15);
  "popped %d, size %d, first %d\n", IntVecPop(nums), nums->size, IntVecGet(nums, 0);
  IntVecRelease(nums);

  PtrVec *words = PtrVecNew();
  PtrVecPush(words, StrNew("banana"));
  PtrVecPush(words, StrNew("fig"));
  PtrVecPush(words, StrNew("kiwi"));
  PtrVecSort(words, &ShorterFirst);
  for (U8 *w : words) {
    "%s\n", w;
  }
  PtrVecRelease(words, &Free);   // frees the strings too
}

Hash tables

StrMap maps strings to U0 * values and IntMap maps I64 keys. Values are pointers, so cast integers when storing them: count(U0 *). Setting an existing key replaces its value.


U0 Main()
{
  StrMap *stock = StrMapNew();
  StrMapSet(stock, "apples", 3(U0 *));
  StrMapSet(stock, "pears", 5(U0 *));
  StrMapSet(stock, "apples", 4(U0 *));
  StrMapSet(stock, "plums", 7(U0 *));
  StrMapDelete(stock, "plums");

  "%d apples, has kiwis: %d, %d keys\n",
    StrMapGet(stock, "apples"), StrMapHas(stock, "kiwis"), stock->size;

  I64 idx = 0;
  StrMapNode *node;
  while (StrMapIter(stock, &idx, &node)) {
    "%s = %d\n", node->key, node->value;
  }
  StrMapRelease(stock);

  IntMap *names = IntMapNew();
  IntMapSet(names, 404, "not found");
  IntMapSet(names, 200, "ok");
  "%s\n", IntMapGet(names, 404);
  "deleted 200: %d, deleted 500: %d\n", IntMapDelete(names, 200), IntMapDelete(names, 500);
  IntMapRelease(names);
}

StrMapGet and IntMapGet return NULL for a missing key, which is also what a stored NULL or 0 gives. Pass a Bool as the optional last argument to tell them apart: it is set to TRUE when the key is there (StrMapHas and IntMapHas answer the same question). StrMapGetLen and StrMapHasLen look up the first key_len bytes at a pointer, so a word inside a larger buffer can be looked up without copying it out. StrMapClear and IntMapClear remove every entry and keep the capacity.


U0 Main()
{
  IntMap *seen = IntMapNew();
  IntMapSet(seen, 7, 0(U0 *));
  Bool ok;
  I64 v = IntMapGet(seen, 7, &ok);
  "7: %d (there: %d)\n", v, ok;
  v = IntMapGet(seen, 8, &ok);
  "8: %d (there: %d)\n", v, ok;

  StrMap *words = StrMapNew();
  StrMapSet(words, "let", 1(U0 *));
  StrMapSet(words, "for", 2(U0 *));
  U8 *line = "for x in xs";
  "first word: %d\n", StrMapGetLen(words, line, 3);

  StrMapClear(words);
  "after clear: %d keys, %d slots\n", words->size, words->capacity;
  StrMapRelease(words);
  IntMapRelease(seen);
}

Iteration (StrMapIter, StrMapKeyIter, StrMapValueIter and the IntMap ones) follows insertion order. Start the cursor at 0 and call until it returns FALSE; the cursor is opaque, so don't compute with it. Deleting entries while iterating is safe (the loop above could delete node->key); adding entries is not, as an added entry can be skipped or the table rebuilt under the loop. A deleted key can be set again and then comes last. StrMapToString, IntMapToString and the KeysToString versions print a map, in insertion order, into a new string you free.

StrMapNew and IntMapNew take an optional starting capacity (default 32): the number of slots, rounded up to a power of two, at least 8 (a negative request gets 8 and one above 228 gets 228). The table is rebuilt, doubling, when its entries and deleted holes fill 60% of the slots, so a capacity of 1024 holds about 600 entries before it grows. It never shrinks, not on delete and not on clear; release it and make a new one to give the memory back. StrMapResize and IntMapResize double it ahead of time. They and the New functions return FALSE or NULL when out of memory, as does a Set that needed to grow the table.

StrMapSetFreeKey, StrMapSetFreeValue and IntMapSetFreeValue register destructors. With them the map owns what you give it: they run on Delete, Clear and Release, and when Set replaces a value. Setting a key that is already there keeps the key the map stores and frees the old value and the key you passed (nothing is freed when you pass the stored pointers again). A pointer used as both the key and the value (StrMapSet(m, s, s)) is freed once. Set returns TRUE for a new key and an update alike; check Has first to know which. A NULL map or key is safe everywhere: Get and Has give NULL and FALSE, Set and Delete FALSE, and Release and Clear do nothing.

The map keeps the key pointer you pass the first time a key is set, instead of copying it. Use keys that live as long as the map, such as StrNew copies; updating an existing key from a reused buffer is fine. With a key destructor registered, an update frees the key you passed: don't use it after StrMapSet returns.

JSON

JsonParse parses text into a tree of Json nodes; the text can be any JSON value (an object, array, string, number, boolean or null). Check JsonOk before using the result. JsonSelect walks a path: .field for object members and [n] for array elements, with a type suffix that must match (:s string, :i integer, :f float, :b boolean, :a array, :o object). It returns NULL if the path or type doesn't match.


U0 Main()
{
  U8 *text = "{\"name\": \"hcc\", \"version\": 15, \"ratio\": 0.75, \"tags\": [\"jit\", \"repl\"], \"stable\": false}";
  Json *doc = JsonParse(text);
  if (!JsonOk(doc)) {
    JsonPrintError(doc);
    return;
  }

  "%s v%d\n", JsonSelect(doc, ".name:s")->str, JsonSelect(doc, ".version:i")->i64;
  "second tag: %s\n", JsonSelect(doc, ".tags[1]:s")->str;
  "stable: %d\n", JsonSelect(doc, ".stable:b")->boolean;
  "missing: %d\n", JsonSelect(doc, ".author:s") == NULL;

  Json *tags = JsonSelect(doc, ".tags:a");
  for (Json *t = tags->array; t; t = t->next) {
    "tag %s\n", t->str;
  }

  "%s\n", JsonToString(doc);
  JsonRelease(doc);
}

Each node has a type (JSON_STRING, JSON_INT, JSON_FLOAT, JSON_BOOL, JSON_NULL, JSON_ARRAY, JSON_OBJECT), a key when it's an object member, its value in str / i64 / f64 / boolean / array / object, and next for its siblings. String escapes are decoded, \uXXXX (and surrogate pairs) to UTF-8. JsonToString writes a float in the shortest form that reads back as the same value, always with a decimal point (0.75, 2.0, 1.0e+21), and escapes strings so the output parses back (\", \\, \n, \t, ... and \u00XX for other control characters).

The optional arguments are the length to parse (-1, the default, reads up to the terminating NUL) and flags. With JSON_STRNUM_FLAG numbers are not converted: each one becomes a JSON_STRNUM node whose strnum is the number exactly as written, so large integers and decimals keep every digit, and JsonToString writes it back unchanged. The :i and :f suffixes don't match these nodes; select them without a suffix.


U0 Main()
{
  Json *doc = JsonParse("{\"id\": 123456789012345678901234567890, \"price\": 9.90}",
                        -1, JSON_STRNUM_FLAG);
  "id %s\n", JsonSelect(doc, ".id")->strnum;
  "price %s\n", JsonSelect(doc, ".price")->strnum;
  "%s\n", JsonToString(doc);
  JsonRelease(doc);
}

price 9.90

Now() returns a TempleOS-style CDate, and Date2Struct / Struct2Date convert between it and a CDateStruct, which has year, mon, day_of_mon, hour, min, sec and day_of_week (0 is Sunday). MPrintDate and MPrintTime return new strings as MM/DD/YYYY and HH:MM:SS. A CDate is an I64 class, an integer underneath, so CDate d = 5; and I64 x = d; need no cast, and F64 f = d; converts it to a float like any integer (a float assigned to a CDate is truncated, as it would be for an I64).

StrToCDate(text, format) parses a date with a strptime-like format and Str2CDateStruct(text, format, &ds) fills a CDateStruct. The conversions are %Y, %m, %d, %H, %M, %s (or %S) for seconds, %a and %b for day and month names (full or three letters, any case), %p for AM/PM, %z for a zone offset and %%; a space in the format matches any run of spaces, other characters must match exactly. Missing time fields are 0. Str2CDateStruct returns FALSE and StrToCDate 0 for empty or short input, text that doesn't match, an unknown conversion or an impossible value (month 13, February 30, hour 24, ...); StrToCDate also needs the year, month and day.


U0 Main()
{
  CDate d = StrToCDate("Mar 5 2024 1:30 PM", "%b %d %Y %H:%M %p");
  U8 *date = MPrintDate(d), *time = MPrintTime(d);
  "%s %s\n", date, time;
  Free(date);
  Free(time);

  CDateStruct ds;
  "%d %d\n", Str2CDateStruct("2023-02-29", "%Y-%m-%d", &ds),
    StrToCDate("2024-03", "%Y-%m-%d") == 0;
}

03/05/2024 13:30:00
0 1

Maths

The C maths library is declared under its usual names (sqrt, pow, sin, floor, fabs, …, all on F64), plus Abs, Gcd and Pow. Gcd ignores signs: Gcd(0, n) is |n| and Gcd(0, 0) is 0.


U0 Main()
{
  "%.4f %.0f %.1f %.1f\n", sqrt(2.0), pow(2.0, 10.0), floor(2.7), fabs(-1.5);
  "%d %d %d %.2f\n", Abs(-5), Gcd(12, 18), Gcd(-4, 0), Pow(1.5, 2);
}

1.4142 1024 2.0 1.5
5 6 4 2.25

Sockets

NetCreateServer(port, bindaddr, backlog) returns a listening TCP socket, NetAccept(server) the next connection on it and NetConnect(addr, port) a connected socket. All three return the socket as an I32, or -1 on failure (0 is a valid socket number). Read and write them with read/write or recv/send, and close them when done.


I32 srv = NetCreateServer(8080, "127.0.0.1", 16);
if (srv == -1) {
  "can't listen on 8080\n";
  return;
}
I32 conn = NetAccept(srv);   // waits for a client
if (conn != -1) {
  write(conn, "hello\n", 6);
  close(conn);
}
close(srv);

More modules

These are covered in the library reference:

  • Threads: pthreads (pthread_create, mutexes, condition variables) plus ThreadWorker helpers.
  • Networking: sockets, getaddrinfo and friends. NetCreateUnixServerSocket(path, backlog) and NetCreateUnixClientSocket(path) make Unix domain sockets; they return -1 on failure, also when the path is longer than 107 bytes on Linux or 103 on macOS. The address classes (sockaddr_in, sockaddr_un, addrinfo, ...) have the platform's C layout, and SOL_SOCKET, SO_*, AF_INET6, IPPROTO_*, TCP_* and AI_* the platform's values.
  • CSV: CsvParserInit and CsvParse, a streaming tokenizer.
  • Fuzzy matching: fzf-style scoring.
  • Sets: red-black-tree-backed integer and string sets.
  • SQLite: when hcc is built with --sqlite.
