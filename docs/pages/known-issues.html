Known issues

Bugs found while writing and testing these docs and while testing the compiler, each with a way to reproduce it and a workaround. The other pages avoid them, so every example there works as shown.

Compiler

ProblemReproduceWorkaround
Print statements don't support the HolyC conversions %Q %D %T %C %F "%Q\n", s; prints %Q: print statements are formatted by C's printf, and the compile-time argument check counts them that way Format with MStrPrint or StrPrint, which support them

Diagnostics

JIT and code generation

No known issues: everything found while writing these docs has been fixed.

Standard library

ProblemReproduceWorkaround
Adding to an RBTree or IntSet while iterating over it can overflow the iterator RBIterNew, RBTreeForEach and IntSetIterNew size their stack from the tree's size when they start, so inserts during the walk can write past it Collect the changes and apply them after the loop
FileRead can't read pipes or /proc files FileRead("/proc/self/status", &len) gives NULL: only regular files are read, by their size Shlurp("cat /proc/self/status"), or open and read until 0
Writing to a socket whose peer has closed kills the program with SIGPIPE Close the accepted socket, then write to the client end twice: the second write raises SIGPIPE, whose default action ends the process, instead of returning -1 Have the peer say when it is done before closing (a length prefix or an end marker), so nothing is written after it closes

Reporting

Please report bugs on GitHub. A minimal .HC file that reproduces the problem helps the most.
