JIT and code generation

ProblemReproduceWorkaround
A function with more than about 64 KiB of local variables gets a stack frame that is too small: the frame size is kept in 16 bits, so only the size modulo 65536 is reserved and the locals lie below the stack pointer, where the next call overwrites them (a crash, or a local array that changes by itself). Compiled and JIT, x86_64 and arm64 U8 tmp[65536]; in a function, fill it, call any function that uses some stack, then read tmp back: on x86_64 a 64 KiB read() into it overwrites the return address Keep large buffers off the stack: MAlloc them, or use a global array; keep the locals of one function under 64 KiB in total
