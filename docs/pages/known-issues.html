Known issues

Bugs found while writing and testing these docs (hcc v0.0.15-beta), each with a way to reproduce it and a workaround. The other pages avoid them, so every example there works as shown.

Compiler

No known issues: everything found while writing these docs has been fixed.

JIT and code generation

ProblemReproduceWorkaround
Calling a variadic (...) function through a function pointer passes the wrong arguments in the JIT and on arm64 I64 (*sp)(U8 *t, ...) = &Sum; sp("a", 1, 2, 3); under -jit Call the function directly, or compile on x86_64
-Memsafe reports leaks and double frees in correct code Three MAllocs and three Frees report one allocation never freed Use valgrind on a compiled binary instead

Standard library

ProblemReproduceWorkaround
StrPrint ignores the width of %s and mixes up its precision StrPrint(NULL, "[%5s][%.2s]", "ab", "abcd") gives [ab][abcd] Pad and cut strings yourself, or use a print statement
StrMapDelete corrupts the table Deleting from a large map can crash; it isn't declared in tos.HH Don't delete from maps; rebuild the map without the key

Reporting

Please report bugs on GitHub. A minimal .HC file that reproduces the problem helps the most.
