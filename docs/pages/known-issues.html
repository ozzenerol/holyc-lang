Known issues

Bugs found while writing and testing these docs (hcc v0.0.15-beta), each with a way to reproduce it and a workaround. The other pages avoid them, so every example there works as shown.

Compiler

No known issues: everything found while writing these docs has been fixed.

JIT and code generation

No known issues: everything found while writing these docs has been fixed.

Standard library

ProblemReproduceWorkaround
%d in print statements is 32-bit "%d", 5000000000; prints 705032704 Use %ld, or StrPrint, whose %d is 64-bit
StrPrint and friends exit on %f StrPrint(NULL, "%f", 1.5) prints "Floats not supported" and exits Format floats with a print statement
JsonToString exits on floats Any JSON containing a float, because of the issue above Keep floats out of JSON you print, or store them as strings
StrCmp / StrNCmp return the wrong sign on x86_64 StrCmp("abc", "abd") is positive Use them for equality (== 0) only, or compare characters yourself
Date2Struct, MPrintDate and MPrintTime crash MPrintDate(Now()) NowDateTimeStruct and MPrintTimestampNow
Gcd returns the wrong answer Gcd(12, 18) is 18 Write your own Euclid loop
Shlurp without format arguments doesn't capture Shlurp("ls") prints to the terminal and returns the exit status as a pointer Pass an argument: Shlurp("%s", "ls")
StrMapNew hangs unless the capacity is a power of two StrMapNew(100), then insert a few hundred keys Use the default, or a power of two such as 128
StrMapSet stores your key pointer, and replaces it on update Setting a key from a reused buffer leaves the map pointing at it Pass keys that live as long as the map (StrNew), and set each key once
STDOUT is 0 and STDIN is 2 in tos.HH Write(STDOUT, ...) writes to stdin, which only works on a terminal Use the numbers: 1 for stdout, 2 for stderr
Libraries built with -lib can't be loaded by the JIT #link <mylib> under -jit: "failed to load library" Symlink libmylib.so to libmylib.so.0.0.1

Reporting

Please report bugs on GitHub. A minimal .HC file that reproduces the problem helps the most.
