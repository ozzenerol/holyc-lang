Known issues

Bugs found while writing and testing these docs and while testing the compiler, each with a way to reproduce it and a workaround. The other pages avoid them, so every example there works as shown.

Compiler

ProblemReproduceWorkaround
An I8, U8 or Bool can't be used as an array index or added to a pointer U8 buf[8], i = 2; buf[i] = 'a'; is an error ("U8[8] + U8 is invalid"), and for buf[i] the error points at the line before; I16 and wider work Use an I64 variable, or cast: buf[i(I64)]

JIT and code generation

No known issues: everything found while writing these docs has been fixed.

Standard library

ProblemReproduceWorkaround
On macOS NetAccept returns a non-blocking socket when the listening socket is non-blocking NetCreateServer(0, "127.0.0.1", 4, AF_INET, TRUE), then NetAccept(srv) without non_blocking: on macOS the accepted socket has O_NONBLOCK (BSD's accept copies it from the listener), so recv returns -1 with Errno() EAGAIN instead of waiting; on Linux it is blocking Clear the flag after accepting: fcntl(fd, F_SETFL, fcntl(fd, F_GETFL, 0) & ~O_NONBLOCK)
