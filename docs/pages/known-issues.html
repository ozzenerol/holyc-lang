Compiler

No known issues: everything found while writing these docs has been fixed.

Standard library

ProblemReproduceWorkaround
NetAccept returns Bool, and NetCreateServer returns 0 on some failures A socket number over 255 from NetAccept is truncated; 0 from NetCreateServer looks like a valid socket Call accept directly, and treat <= 0 from NetCreateServer as failure
Unix domain sockets don't work on Linux sockaddr_un has the BSD layout (a leading length byte), so NetCreateUnixServerSocket fails and returns 0; a path over 104 bytes also overflows it Use TCP on 127.0.0.1

Reporting

Please report bugs on GitHub. A minimal .HC file that reproduces the problem helps the most.
