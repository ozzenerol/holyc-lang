Standard library

ProblemReproduceWorkaround
On macOS a program started by ProcSpawn has no stdin, stdout or stderr when they are PROC_INHERIT (the default) ProcSpawn(argv) with argv {"echo", "hi", NULL}, then ProcWait: Linux prints hi and gives 0; macOS prints nothing and gives 1. ProcSpawn sets POSIX_SPAWN_CLOEXEC_DEFAULT to close our other fds, and on macOS that closes 0-2 as well unless they are named with posix_spawn_file_actions_addinherit_np Use PROC_PIPE (or ProcRun / ProcCommunicate) and pass the output on yourself, or Sh for a command line
