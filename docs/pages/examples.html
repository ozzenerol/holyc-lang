Example projects

Four complete programs in docs/examples/, each with the exact output it should produce. They double as tests: docs/examples/run.sh builds every project, runs it both compiled and in the JIT, and compares the output with its expected.txt.

docs/examples/run.sh          # all projects
docs/examples/run.sh life     # just one

Word frequency

Reads a text file and prints its most common words. It shows reading a file, scanning characters, counting with a StrMap, ranking with PtrVecSort, and reading command-line arguments.

cd docs/examples/wordfreq
hcc main.HC -o wordfreq && ./wordfreq sample.txt

Bank

Accounts with monthly interest and a transaction log. A savings account inherits from Account and swaps in its own interest function through a function pointer. Errors are exceptions, and a failed transfer rolls itself back. Money is kept in integer cents, so no rounding errors creep in.

cd docs/examples/bank
hcc main.HC -o bank && ./bank

Game of Life

Conway's Game of Life on a small board that wraps at the edges, with a glider and a blinker. It shows 2D arrays, nested loops, % for wrap-around and MemCpy on whole arrays.

cd docs/examples/life
hcc main.HC -o life && ./life

Echo server

A TCP echo server that handles every connection in its own coroutine, all on one thread. Each connection's code reads like blocking code: when a read or write would block (Errno() == EAGAIN on a non-blocking socket) the coroutine records what it is waiting for and yields, and the main loop's poll() resumes it once its socket is ready. Run without arguments it tests itself: four client threads connect over loopback, each sends three lines and checks the echo, and the server stops once they are done. With a port it serves until stopped.

cd docs/examples/echo
hcc main.HC -o echo && ./echo          # self-test
./echo 7000                            # then: nc 127.0.0.1 7000

More examples in the repository

The compiler's own test suite, src/tests/, has more than 300 small programs, one per feature or fixed bug: threads, sockets, JSON, SQLite, fuzzy matching and more. The standard library in src/holyc-lib/ is all HolyC too, and worth reading.
