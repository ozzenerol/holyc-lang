Known issues

Bugs found while writing and testing these docs and while testing the compiler, each with a way to reproduce it and a workaround. The other pages avoid them, so every example there works as shown.

Compiler

ProblemReproduceWorkaround
A local declaration accepts a class value into an integer P p; I64 z = p; inside a function is only a warning and stores the class's address; assigning (y = p) or a global I64 gz = gp; are errors Treat the warning as an error, or build with -Werror
The C transpiler crashes on a cast after a double dereference I64 v = **pp(I64 *); with Pt **pp makes -transpile print "Unary type is being assigned as NULL" and segfault The transpiler is experimental; split the expression

Diagnostics

ProblemReproduceWorkaround
An escaped character constant is misprinted in errors I64 s = 2 '\n' 3; reports "Unexpected character constant `\`" instead of showing '\n' Look at the caret position
A function pointer without a name gives a second, bogus error I64 (*)(I64 x); reports "Expected function pointer name" and then "Cannot handle 'TK_PUNCT )'" Read only the first error

JIT and code generation

No known issues: everything found while writing these docs has been fixed.

Standard library

No known issues: everything found while writing these docs has been fixed.

Reporting

Please report bugs on GitHub. A minimal .HC file that reproduces the problem helps the most.
